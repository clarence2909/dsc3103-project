The cleaning removed negative prices, duplicate records, and invalid dates, while commodity names were changed to a consistent title-case format such as `Maize` and `Beans`. An outlier is a value that is very different from the others. I treated negative prices as errors, not outliers, because a price cannot be below zero in this dataset. The market rule found `none` values, although the current cleaner only fills blank values, so those values were not changed. Leakage would happen if information from the target or from the future, such as `total price` calculated from the outcome, were used to create prediction features before the prediction time.
